# SantaTeams Bot

Telegram-бот для гри «Таємний Санта»: [@SantaTeamsBot](https://t.me/SantaTeamsBot).

> **Статус: працює, чекає на першу реальну гру.**
> Це третє покоління бота. v1 (Excel, один файл) відіграла живу гру на 15 людей
> у грудні 2025 і показала себе добре. v2 (Google Sheets) до запуску не дійшла —
> її добудова втратила сенс, і проєкт переписано з нуля. v3 — цей репозиторій:
> запущений, пройшов ручний прогін повного циклу (команда → анкети →
> жеребкування → розсилка), але в бойовій грі з живою командою ще не був.

Будь-хто може зібрати команду, скинути посилання-запрошення в робочий чат,
дочекатись анкет і провести жеребкування — кожному учаснику в особисті
повідомлення прийде анкета людини, якій він таємно дарує подарунок.
Організатор грає нарівні з усіма й не бачить пар (хіба що дуже попросить —
бот двічі перепитає, чи точно він хоче зіпсувати собі сюрприз).

## Можливості

- Команди з інвайт-кодами: приєднання за посиланням `t.me/...?start=КОД`,
  ручним кодом або точковим додаванням.
- Постійні команди (грають щороку тим самим складом) і одноразові
  (після гри архівуються, анкети видаляються за графіком ретенції).
- Анкета: ПІБ, телефон, відділення Нової пошти, алергії, побажання.
  Торішню анкету можна підтвердити одним натисканням.
- Жеребкування кільцем: ніхто не дарує собі, кожен отримує рівно один
  подарунок. Розсилка зі статусом доставки та повтором для тих, хто
  заблокував бота.
- Ролі: звичайний користувач (до 5 команд по 50 учасників), керівник
  (до 10 по 100, роль видає адміністратор), адміністратор. Ліміти
  налаштовуються глобально й персонально.
- Захист: анти-флуд, лише приватні чати, скарги на користувачів,
  глобальний бан, вимикач реєстрації нових команд.

## Стек

Python 3.12 · [aiogram 3](https://docs.aiogram.dev) · SQLite (aiosqlite) ·
long polling. Стан анкет і майстрів зберігається в БД — рестарт нічого не губить.

## Запуск локально

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписати BOT_TOKEN і ADMIN_ID
python -m app.main
```

Тести:

```bash
pip install pytest
pytest
```

## Запуск у Docker

```bash
cp .env.example .env            # вписати BOT_TOKEN і ADMIN_ID
mkdir -p data && chown -R 1000:1000 data   # контейнер працює під uid 1000
docker compose up -d --build
```

База лежить у `./data/santa.db`, щоденний бекап — у `./data/backups/`
(зберігаються останні 14). Контейнер обмежений 256 МБ памʼяті та 0.5 CPU,
логи ротуються самим Docker. Детальніше про бойовий деплой —
[deploy/DEPLOY.md](deploy/DEPLOY.md).

## Структура

```
app/
├── main.py          точка входу: збірка, фонові задачі, polling
├── config.py        оточення (падає на старті без токена)
├── texts.py         всі тексти українською
├── keyboards.py     клавіатури та callback-фабрики
├── states.py        FSM-стани майстрів
├── db/              схема, зʼєднання, запити, FSM-storage у SQLite
├── middlewares/     анти-флуд і контроль доступу
├── routers/         хендлери: старт, команди, анкета, гра, адмінка
└── services/        чиста логіка: жеребкування, доставка, ліміти, валідація
```

## Дані та приватність

Анкети містять персональні дані (ПІБ, телефон, адреса відділення) і
використовуються лише для доставки подарунків. В одноразових командах
після завершення гри анкети одразу зникають для учасників, архівна копія
доступна організатору 14 днів (керівнику — 30) і видаляється остаточно
не пізніше ніж за рік. Пароль доступу не потрібен: потрапити в команду
можна лише за її інвайт-кодом.
